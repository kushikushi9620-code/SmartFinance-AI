# 💰 SmartFinance AI

SmartFinance AI is an AI-powered personal finance management system designed to help users manage their income, expenses, budgets, savings goals, and financial decisions.

## 🚀 Features

- User Signup and Login
- Personal Dashboard
- Income Management
- Expense Tracking
- Edit and Delete Expenses
- Search Expenses by Category
- Budget Planning
- Savings Goal Tracking
- Expense Analytics
- AI Financial Advisor
- AI-based Expense Analysis
- Financial Reports
- User Profile
- Change Password

## 🤖 AI Financial Advisor

The application includes an AI-powered financial advisor that provides simple and practical financial guidance based on user questions.

The advisor is designed for Indian users and provides financial examples using Indian Rupees (₹).

## 🛠️ Technologies Used

### Frontend

### Backend
- Python

### AI
- Google Gemini API

## 📊 Project Purpose

The main purpose of SmartFinance AI is to help users:

- Track their daily financial activities
- Understand their spending patterns
- Plan monthly budgets
- Set savings goals
- Receive AI-based financial guidance
- Make better financial decisions
